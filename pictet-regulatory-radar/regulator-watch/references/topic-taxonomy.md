# Topic Taxonomy

Controlled vocabulary used by `regulator-watch` to tag items and by users to filter digests. Keep the list short and stable — it is easier to merge tags than to split them later.

## Core topics (private-banking relevant)

| Tag | Covers |
|---|---|
| `aml` | Anti-money laundering, CDD, KYC, beneficial ownership, sanctions |
| `suitability` | Suitability, appropriateness, FinSA, MiFID II conduct |
| `cross-border` | Cross-border solicitation, branch licensing, RM travel |
| `client-protection` | Disclosures, fees, complaints handling, ombudsman |
| `conduct` | Market conduct, conflicts of interest, gifts, PA dealing |
| `data` | Data protection, banking secrecy, cyber, AI use |
| `esg` | Sustainability, climate disclosures, greenwashing, exclusions |
| `capital` | Capital adequacy, liquidity, large exposures, Basel |
| `funds` | Collective investment schemes, fund distribution, FinIA |
| `crypto` | Crypto-assets, DLT, stablecoins, virtual assets |
| `reporting` | Regulatory reporting, returns, supervisory data submissions |
| `enforcement` | Enforcement actions, sanctions imposed, public reprimands |

## Adjacent (medium relevance)

| Tag | Covers |
|---|---|
| `payments` | Payment systems, instant payments — relevant for transaction monitoring |
| `consumer-credit` | Mortgages, lending — relevant for HNW lending products |
| `corporate-governance` | Board composition, fit-and-proper, remuneration |

## Out of scope (skip unless explicitly requested)

- Retail banking pricing
- Insurance product regulation
- Pension fund supervision (BVG/LPP) — *unless* it intersects with mandates Pictet operates
- Statistical releases without policy content

## Adding tags

Tags should only be added when there is a sustained reason to filter on them. Adding a tag for a single news item is over-fitting.
