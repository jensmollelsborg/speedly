# Regulator Source URLs

Authoritative list of publication pages used by the `regulator-watch` skill. **Only fetch URLs from this list.** Update this file when sources change.

Verified: 2026-05-26 (please re-verify quarterly).

## Switzerland — FINMA (Swiss Financial Market Supervisory Authority)

| Source | URL | Notes |
|---|---|---|
| News (all) | https://www.finma.ch/en/news/ | Press releases, enforcement, supervisory communications |
| Circulars | https://www.finma.ch/en/documentation/circulars/ | Binding interpretation of supervisory law |
| Guidance | https://www.finma.ch/en/documentation/finma-guidance/ | Non-binding clarifications |
| Consultations | https://www.finma.ch/en/documentation/consultations/ | Open and closed consultations |
| Enforcement decisions | https://www.finma.ch/en/enforcement/ | Public enforcement reports |
| Annual / strategic reports | https://www.finma.ch/en/finma/publications/ | Risk monitor, annual report, etc. |

Language fallback order: EN → FR → DE → IT.

## When sources change

If a URL returns 404 or has been restructured, do **not** guess the new path. Report the broken source in the digest's "Notes & caveats" section and flag for the bundle maintainer to update this file.
