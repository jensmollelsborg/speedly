# Materiality Rubric

Heuristics for classifying each requirement as High / Medium / Low materiality for Pictet. This is a rule of thumb to keep classifications consistent across assessments — not a formal Compliance taxonomy.

## High materiality — at least one of:

- Requires a **new control or process** that Pictet does not currently have
- Requires a **system or data change** (reporting feeds, new fields, identifier changes)
- Materially changes **client interaction** (new disclosures, onboarding flow changes, suitability questions)
- Tightens **AML / sanctions** obligations or beneficial-ownership requirements
- Tightens **cross-border** rules in jurisdictions where Pictet actively books (CH, HK, SG, LU, UK)
- Introduces or raises **enforcement risk** (e.g. new individual accountability regime)
- Requires **board-level governance** (named committee, attested sign-off)

## Medium materiality — at least one of:

- **Refines** an existing requirement (e.g. revised template, clarification)
- Requires **policy text updates** but not process change
- **New reporting** but in an area Pictet already reports on
- **Disclosure** changes that can be batched with the next prospectus/report cycle

## Low materiality — at least one of:

- **Sector-wide** rule with limited direct Pictet impact
- **Retail-banking** focused with marginal carry-over
- **Industry consultation** with no Pictet-specific exposure
- **Statistical / data** submissions Pictet is exempt from

## Edge cases

- **Consultations** — score the *expected* materiality if adopted as drafted. Flag the consultation deadline separately.
- **Guidance vs Circulars** — same content classifies the same, but if non-binding, note "guidance, not binding" in the materiality column.
- **Enforcement decisions** — generally not "requirements" themselves; capture as context in §7 (Open questions) if they signal a likely policy direction.
